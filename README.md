# Yoru | AI 캐릭터 라운지

아이폰 Safari에 맞춘 제타풍 다크 테마 캐릭터 채팅 웹 앱의 첫 번째 실행 버전입니다.

## 현재 구현된 기능
- 캐릭터 목록, 프로필, 직접 캐릭터 생성/수정
- 캐릭터별 대화 기록을 브라우저 localStorage에 저장
- 관계 점수 0~100과 관계 단계 표시
- 최근 대화 문맥을 AI API 요청에 포함
- 8번의 사용자 메시지마다 최근 대화 주제를 간단한 기억 메모로 저장
- API 미설정 상태에서도 작동하는 데모 대화 모드
- 대화 JSON 내보내기, 대화 초기화, 로컬 데이터 삭제
- 모바일 반응형 UI 및 홈 화면 추가용 웹 앱 manifest

## 가장 쉬운 실행 방법: GitHub Pages
1. GitHub에서 새 저장소를 만듭니다. 예: `yoru-chat`
2. `index.html`, `manifest.json`, `README.md`를 저장소 루트에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치와 `/(root)`를 지정한 뒤 저장합니다.
5. 배포가 끝나면 표시되는 `https://사용자이름.github.io/yoru-chat/` 주소를 아이폰 Safari로 엽니다.
6. Safari의 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 실행할 수 있습니다.

## 실제 AI 응답 연결
⚠️ 빠른 시작 버전의 API 키는 브라우저 localStorage에 저장됩니다. 본인 기기에서 시험할 때만 사용하세요. 공개 앱이나 다른 사람에게 배포할 버전은 API 키를 서버 환경변수에 보관하는 백엔드 프록시를 추가해야 합니다.

1. OpenRouter 또는 다른 OpenAI 호환 API 제공자에서 API 키와 모델 ID를 준비합니다. 무료 모델이 제공되는지는 제공자 페이지에서 확인하세요. 무료 모델은 속도, 가용성, 사용량 제한이 달라질 수 있습니다.
2. 앱 오른쪽 위 ⚙ 설정을 엽니다.
3. **실제 AI API 사용**을 켭니다.
4. API 주소, 모델 ID, API 키를 입력하고 저장합니다.
   - OpenRouter 기본 주소: `https://openrouter.ai/api/v1/chat/completions`
   - 모델 ID는 제공자가 표시하는 정확한 ID를 입력해야 합니다.
5. 채팅으로 돌아가 테스트합니다. 오류가 나면 주소, 모델 ID, 잔여 사용량, 브라우저 네트워크 제한을 확인하세요.

## 기억 기능의 한계
현재 기억은 **이 기기의 브라우저에 저장**됩니다. 다른 기기와 동기화되지 않으며 Safari 웹사이트 데이터 삭제 시 사라질 수 있습니다. AI에 보내는 장기 기억은 현재 캐릭터 설정과 간단한 최근 주제 메모를 사용합니다. 서버 기반 계정/클라우드 동기화는 다음 단계에서 추가해야 합니다.
